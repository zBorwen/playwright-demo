# UI 设计系统 — Playwright 自动化平台

## 1. 布局框架

采用 **三栏式 DevTools 布局**：左侧导航 + 顶部标题栏 + 主内容区，必要时右侧可展开详情面板。

### 1.1 结构

```
┌─────────────────────────────────────────────┐
│  Header (48px) — 项目名 / 全局搜索 / 用户    │
├──────────┬──────────────────────────────────┤
│ Sidebar  │  Content Area                    │
│ (220px)  │  (flex-1, scrollable)            │
│          │                                  │
│ 导航菜单  │  页面内容                         │
│ 项目列表  │  卡片 / 表格 / 时间线              │
│ 快捷操作  │                                  │
├──────────┴──────────────────────────────────┤
│  Status Bar (28px) — 运行状态 / 录制计数      │
└─────────────────────────────────────────────┘
```

**Sidebar 内容层级**：

1. **Logo + 项目名称**（顶栏，24px 高）
2. **主导航** — 仪表盘、录制、回放、设置（带图标）
3. **项目列表** — 可折叠，每个项目一个条目
4. **最近活动** — 底部收起面板，显示最近 3 条执行记录

**原则**：侧边栏固定不动，内容区独立滚动。右侧面板（录制详情）按需滑入，不常驻占位。

## 2. 色彩系统

基于 `zinc` 暗色基调，叠加语义色。所有颜色值使用 Tailwind 色阶。

### 2.1 中性色阶

| 用途 | Token | 值 |
|------|-------|-----|
| 背景最深 | `bg-zinc-950` | `#09090b` |
| 背景主体 | `bg-zinc-900` | `#18181b` |
| 卡片/面板 | `bg-zinc-800` | `#27272a` |
| 悬浮态 | `bg-zinc-700` | `#3f3f46` |
| 分割线 | `border-zinc-700/50` | `rgba(63,63,70,0.5)` |
| 次级文字 | `text-zinc-400` | `#a1a1aa` |
| 主体文字 | `text-zinc-100` | `#f4f4f5` |
| 强调文字 | `text-white` | `#ffffff` |

### 2.2 语义色

| 语义 | 基础 | 背景 | 文字 | 边框 |
|------|------|------|------|------|
| **成功 / 通过** | `green-500` | `green-500/10` | `green-400` | `green-500/30` |
| **失败 / 错误** | `red-500` | `red-500/10` | `red-400` | `red-500/30` |
| **运行中** | `blue-500` | `blue-500/10` | `blue-400` | `blue-500/30` |
| **警告** | `yellow-500` | `yellow-500/10` | `yellow-400` | `yellow-500/30` |
| **等待 / 排队** | `zinc-500` | `zinc-500/10` | `zinc-400` | `zinc-500/30` |

语义色使用原则：**背景色永远带透明度**，不抢视觉焦点。文字用 400 色阶，足够醒目但不过亮。仅在高优先级告警时用 500。

### 2.3 品牌色

主色使用 `violet-500`（`#8b5cf6`），替代默认的蓝色，形成差异化。用于：

- 主按钮
- 激活态导航项
- 链接
- 进度条主色

## 3. 字体与排版

### 3.1 字体栈

```
font-sans: Inter, system-ui, -apple-system, sans-serif
font-mono: JetBrains Mono, Fira Code, monospace  （代码/时间戳/ID）
```

### 3.2 字号层级

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| `xs` | 11px | 400 | 标签、时间戳、计数徽章 |
| `sm` | 13px | 400/500 | 列表项、描述文字、表单标签 |
| `base` | 14px | 400/500 | 正文默认 |
| `lg` | 16px | 500/600 | 卡片标题、小标题 |
| `xl` | 20px | 600 | 页面标题 |
| `2xl` | 24px | 700 | 仪表盘关键指标数字 |

**行高**：默认 `1.5`，标题 `1.25`，表格行紧凑模式 `1.3`。

## 4. 组件模式

### 4.1 卡片

```
┌──────────────────────────────────┐
│ [图标] 项目名称           [状态]  │  ← 标题行，14px semibold
│                                  │
│ 描述文字...              12 录制  │  ← 副信息行，13px muted
│ ─────────────────────────────── │
│ 最近运行: ✅ 2分钟前   ⏱ 3.2s   │  ← 底部指标行
└──────────────────────────────────┘
```

- 背景：`zinc-800`，边框：`zinc-700/50`，圆角 `lg`（8px）
- 悬浮：边框变 `zinc-600`，背景微亮 `zinc-750`，`transition-all 150ms`
- 点击态：`scale-[0.99]` 微缩反馈

### 4.2 状态徽章（Badge）

小胶囊样式，替代 emoji。圆角 `full`，内边距 `px-2 py-0.5`，字号 `xs`，字重 `500`。

| 状态 | 图标 (lucide) | 颜色 |
|------|---------------|------|
| 通过 | `CheckCircle` | `green` |
| 失败 | `XCircle` | `red` |
| 运行中 | `Loader2`（旋转动画） | `blue` |
| 排队中 | `Clock` | `zinc` |
| 警告 | `AlertTriangle` | `yellow` |
| 录制中 | `Circle`（红点 pulse） | `red` |

运行中的 `Loader2` 加 `animate-spin`。录制中的红点加自定义 pulse 动画（`animate-pulse`）。

### 4.3 按钮层级

| 层级 | 样式 | 场景 |
|------|------|------|
| Primary | `violet-500` 背景，白字 | 创建录制、开始回放 |
| Secondary | `zinc-700` 背景，白字 | 次要操作 |
| Ghost | 透明背景，悬浮 `zinc-700` | 工具栏图标、删除 |
| Danger | `red-500/10` 背景，`red-400` 文字 | 删除、停止录制 |

所有按钮：圆角 `md`（6px），内边距 `px-3 py-1.5`，字号 `sm`，`transition-colors 100ms`。

### 4.4 表格 / 列表

录制列表使用表格布局，紧凑高密度：

```
│ 名称       │ 状态   │ 持续时间 │ 执行时间     │ 操作  │
│ login-test │ ✅ 通过 │ 3.2s    │ 2分钟前      │ ▶ 🗑  │
│ checkout   │ ❌ 失败 │ 1.8s    │ 1小时前      │ ▶ 🗑  │
```

- 行高 `40px`，分割线 `zinc-700/30`
- 行悬浮：`bg-zinc-800/60`
- 操作列默认隐藏，行悬浮时淡入

### 4.5 进度指示器

回放进度条：

```
●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●─────────
0:00                              2:30       3:00
```

- 轨道：`zinc-700`，高 4px，圆角 `full`
- 填充：`violet-500`
- 手柄：直径 12px 圆点，悬浮放大至 14px
- 步骤标记：已完成 `green-500`，当前 `violet-500` 带光晕，未执行 `zinc-600`

## 5. 交互模式

### 5.1 加载状态

**骨架屏**替代旋转加载器：

- 卡片骨架：灰色块 `zinc-700/30` 带 `animate-pulse`
- 列表行骨架：3 条横线，宽度递减
- 骨架屏与真实内容同尺寸同布局，避免跳变

**渐进式加载**：先出框架（侧边栏 + 标题），再出内容骨架，数据到达后渐显替换（`opacity-0 → opacity-100, 200ms`）。

### 5.2 悬浮反馈

- 可点击元素悬浮时加 `cursor-pointer` + 背景/边框色变化
- 卡片悬浮微抬升：`translateY(-1px)` + 阴影增强
- 操作按钮组：行悬浮时显示，`opacity-0 → opacity-100, 150ms`

### 5.3 焦点状态

所有交互元素支持键盘导航：

- 焦点环：`outline-2 outline-violet-500 outline-offset-2`
- 移除默认浏览器焦点环，统一替换为品牌色

### 5.4 过渡动画

| 场景 | 动画 | 时长 |
|------|------|------|
| 页面切换 | 内容区 `fade-in` | 200ms |
| 面板滑入 | `translateX(100%) → 0` | 250ms, `ease-out` |
| 徽章出现 | `scale-90 → scale-100` | 150ms |
| 删除确认 | 行先 `opacity-0` 再折叠高度 | 200ms + 200ms |
| 模态框 | 背景遮罩 `fade-in` + 内容 `scale-95 → 100` | 200ms |

## 6. 仪表盘视觉层级

### 6.1 视线引导

用户进入仪表盘的视觉路径（F 型扫描）：

```
1. 顶部关键指标（4 个数字卡片）
   ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
   │ 总录制  │ │ 今日执行│ │ 通过率  │ │ 平均耗时│
   │   47   │ │   23   │ │  94%   │ │  2.1s  │
   └────────┘ └────────┘ └────────┘ └────────┘

2. 左侧 → 最近失败录制（红色醒目，需要立刻处理）

3. 右侧 → 项目健康度列表（绿/红条状指示器）

4. 下方 → 近期执行趋势（小型折线图）
```

### 6.2 密度原则

- 仪表盘采用 **紧凑卡片 + 数据网格**，不做大面积留白
- 关键数字用 `2xl` 字号 + `semibold`，秒级可读
- 辅助信息用 `xs` + `zinc-400`，不干扰主数据
- 失败项用红色边框 + 红色图标双重标记，确保醒目

### 6.3 时间线（回放详情页）

时间线设计为 **视频播放器** 隐喻，不是列表：

```
┌────────────────────────────────────────────┐
│ [⏮] [◀▶] [⏭]     ●━━━━━━━○━━━━━━━●────  │
│ 0:12 / 2:30       click    type   submit  │
├────────────────────────────────────────────┤
│                                            │
│  [浏览器视口 — 回放快照]                    │
│                                            │
├────────────────────────────────────────────┤
│ 步骤时间线（紧凑列表）                      │
│ │ 1  ✅ 导航到登录页        0:00  +0.2s    │
│ │ 2  ✅ 输入用户名          0:01  +1.1s    │
│ │ 3  ✅ 点击登录按钮        0:02  +0.3s    │
│ │ 4  ❌ 断言失败: 预期首页   0:03  +0.8s   │
└────────────────────────────────────────────┘
```

- 时间轴上方：播放控制 + 进度条
- 中间：浏览器快照视口（带设备外框）
- 下方：步骤列表，失败行红色高亮 + 自动滚动到该步骤
- 步骤行悬浮：高亮对应的进度条位置

## 7. 响应式断点

| 断点 | 宽度 | 行为 |
|------|------|------|
| 桌面 | >= 1280px | 完整三栏布局 |
| 平板 | 768-1279px | 侧边栏折叠为图标栏（64px） |
| 手机 | < 768px | 侧边栏隐藏为汉堡菜单，单栏内容 |

当前阶段以 **桌面端（1280px+）** 为主，其余断点后续适配。
